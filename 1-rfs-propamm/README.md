# 支柱 2：现货交易层 —— Fluxion RFQ & Prop AMM（做市商私有报价层）

> **产品定位**：全资产最优执行的做市商私有库存报价场所（Private Inventory Market Making Layer）  
> **核心使命**：将 Fluxion 在 xStocks 上验证的 Atomic RFQ 机制泛化至 BTC、ETH、MNT 及稳定币等全量主流资产，由 Bybit 自营库存（W2 工作流）直接提供紧贴 CEX 点差的链上深度，终结补贴驱动的虚假流动性。  
> **战略方向**：对现有生态「收敛而非重复建设」——从 28 个割裂休眠的 DEX 收敛至 **Fluxion（主流资产 RFQ/Prop 核心场）+ Agni（长尾 AMM）**。

---

## 1. 为什么是 Prop AMM / RFQ 而非通用 AMM？

### 1.1 历史教训：流动性补贴模式彻底破产
- Mantle 链上曾部署 28 个 DEX，其中 15 个已彻底休眠，前 3 名占据了 99% 的交易量。
- Aave 与各类 DEX 激励活动曾将 TVL 推至高位，但激励一旦退坡，TVL 迅速崩塌（如 Aave 出现 $137M → $704M → $62M 的断崖下跌）。
- **结论**：在日均真实交易量仅 $0.94M 的现状下，继续补贴散户 LP 只是给套利者输送租金。

### 1.2 Mantle 的四重结构优势（天生适合 Prop AMM）
1. **天然抗夹（无公开 Mempool）**：
   Mantle 采用单 Sequencer 架构且无公开交易池。做市商的私有报价在提交至链上打包时，**在物理上不可能被第三方套利者夹（Sandwich Attack）**。这是全网极少被正视的制度性优势。
2. **零排放做市（Zero-Emission Liquidity）**：
   采用 SolFi / Obric / Hashflow 架构，由专业做市商（Bybit 及合作 MM）直接基于自有库存报价，无需协议发放任何 MNT 补贴，彻底杜绝佣金农夫。
3. **聚合器基础设施完备**：
   OKX DEX、KyberSwap、LI.FI 等主流全链流动性聚合器已深度集成 Mantle。Fluxion 接入聚合器路由后，全网用户在兑换主流资产时自动获得最低滑点与最优报价。
4. **链级专属保护协同**：
   结合 Mantle v3 链基础设施升级：**毫秒级预确认流**保证报价新鲜度，**做市商撤单优先规则（Cancel Priority）**防止行情剧烈波动时陈旧报价被恶意扫货。

## 2. 核心架构与业务流程

```
 交易用户 / 聚合器 (OKX / Kyber)
           │ 询价 (Request for Quote)
           ▼
 ┌─────────────────────────────────────────────────────────┐
 │ Fluxion Off-chain Quote Engine (链下做市撮合引擎)        │
 │ 接入 Bybit 自营库存 (W2) + 外部做市商多源报价          │
 └─────────────────────────┬───────────────────────────────┘
                           │ 签署 EIP-712 结构化订单 (含有效期)
                           ▼
 ┌─────────────────────────────────────────────────────────┐
 │ Mantle Sequencer (交易所专用排序器)                      │
 │ 做市商 Cancel 指令享受优先通道 / 预确认流保护           │
 └─────────────────────────┬───────────────────────────────┘
                           │ 打包提交
                           ▼
 ┌─────────────────────────────────────────────────────────┐
 │ Fluxion Atomic Settlement Contract (链上原子结算合约)    │
 │ 验证做市商签名 ──► 资产原子交割 ──► 零滑点完成交易      │
 └─────────────────────────────────────────────────────────┘
```

## 3. 开闭市双模机制（Dual-Mode Trading Engine）

由于代币化股票（xStocks）与传统美股交易时间紧密绑定，Fluxion 独创开市/休市双模机制：
- **开市阶段（美股交易时段 24/5）**：
  做市商基于纽交所/纳斯达克实时 Level 2 行情持续推送毫秒级紧密买卖价，滑点近乎为零，大额订单直接成交。
- **休市阶段（美股周末及夜间）**：
  做市引擎自动切换为保护模式。扩大基差点差，或路由至 Uniswap v4 缓冲池，结合链上市场日历与预言机偏离检测，自动防御跨时段行情跳空风险。
