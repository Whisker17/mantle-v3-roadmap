## X1：Perps 产生交易需求，tokenized assets 承接库存与纠错

**关键段落**：第二节“为什么 Perp 更容易做到价格发现”、第十二节“Perp 成交越大，bStocks 的库存作用越突出”、第十三至十六节关于资产支持、库存流动与借券，以及结语。

作者的主要论点：

- 股票市场休市时，消息和风险偏好仍在变化。Perps 允许参与者继续表达方向、杠杆和对冲需求，形成下一次现金市场开盘前的候选价格。
- Perps 和 tokenized stock 不必互相替代：前者承担多空与高频风险调整，后者可以成为可持有、转移、融资和对冲的现货库存。
- 客户净做多合约时，承接订单的做市商可能成为合约净空头，并买入现货对冲。反向订单则可能引起卖出现有库存或借入现货卖出。只有未被内部抵消的净风险才需要外部对冲，不是每笔合约都产生现货买盘。
- 现货偏便宜时，“买现货、空合约”相对容易构造；现货偏贵时，“卖空现货、多合约”通常还需要可借库存。抵押股票借稳定币是融资，借入股票代币再卖出才是借券式卖空，两者不能混写。
- 上链后增加抵押用途，并不自动增加市场买卖盘。库存能否被用于报价、对冲和交易，才决定这些连接是否有效。

**文章自己保留的边界**：作者对闭市至重开的样本分析并未证明稳定的周末价格领导能力；成交量、方向判断、可执行深度是不同指标。资产支持与申赎关系也不能让休市时的跨市场套利瞬间完成。

**用于 Mantle 的推论**：如果 mStocks 是核心资产，需要同时建设它的交易与风险使用场景。Perps 提供持有现货之外的参与理由，做市与套利有机会把合约订单连接到 mStocks 库存。该推论不表示 bStocks 的流动性、借券或申赎条件已在 mStocks 上成立。

**对应页面**：P14、P14A、P15、P15A、P15B。

## X2：小盘股可能缺少的，是整个多空风险市场

**关键段落**：“小盘股缺的不是故事，缺的是赌场”“不是所有小盘股都会变成 BNC”“Perp 真正创造的是额外的风险容量”“下一步真正值得盯的，是周末谁给周一开盘”“最大的风险也就在这里”。

作者的主要论点：

- 对一些小盘股，全球关注和交易意愿已经存在，但现货、期权、借券或非交易时段工具不足。Perps 的增量可能是一整个此前缺失的多空风险市场；大盘股原有工具较完整时，同一新增产品的边际作用通常不同。
- 流通股数量限制现货所有权供给，却不构成合约名义风险敞口和期间换手的机械上限。公司不必先增发，其他参与者仍可在保证金与风控约束下建立多空仓位，并持续调整。
- 作者以 BNC 为交易需求较突出的观察样本，又以 ONDS、AAOI 提醒读者：传统市场本来就活跃、工具齐全时，增加一个股票合约不一定带来同等增量。
- OI 是未平仓合约的名义规模，不是收入、净新增资金或新发行股票。市场运营者可能获得费用与做市机会，但股票发行人不自动从外部合约交易中获得收益。
- 非交易时段缺少新鲜现金市场价格时，需要特别处理参考价格、标记价格、资金费与清算的关系，防止市场报价与强平互相放大。

**用于 Mantle 的推论**：根据本轮产品方向，应把有交易关注、但传统工具不足的小市值币股作为 Mantle 股票 Perps 的优先场景。论证顺序是“缺少什么市场—Perps 能扩展怎样的参与与风险容量—链上 mStocks 与协议组合如何支持它”，而非只提出一般性的上币筛选条件。价格、库存和做市资本是该定位落地的前提，不替代定位本身。

**P14C 使用的历史样本**：X2 在开篇记录 2026-09-08 的 BNC Perps OI 约 8,800 万美元，超过流通股价值一半。该数据由作者给出，本次未独立复算；仅说明外围风险市场可能达到的量级。OI 不是保证金、新融资或平台收入，不将不同窗口的成交量直接作倍数比较。

**不采用的表达**：不把“赌场”“必将取代股票”等修辞带入本次文案；不将文章的成交量、OI 或市值比率作为 Mantle 的收入预测；不引用免税或无监管承诺。

**对应页面**：P14A、P14B、P14C、P14D、P19、P20。

## X3：不同交易理由可以带来同一笔资产需求

**关键段落**：“水果摊阿伯都懂的道理”“永续合约背后的4个价格”“资金费率与成本”“价差和套利”“凭空增加的博弈点？”以及结尾的参与者总结。

作者的主要论点：

- 做市商持有股票可能是为了服务合约客户，而非判断股票会上涨。现货库存可以与合约仓位组合，降低方向风险。
- 资金费策略让不想判断涨跌的交易者也有参与理由。收入来自合约另一侧，必须扣除融资、借券、成交与其他成本；资金费可以改变方向。
- 价差策略关心现货与合约之间的偏离能否缩小。永续没有固定到期交割日，不能保证到某天收敛，更不能把价差直接写成已实现利润。
- 普通用户做空 Perps 可以不亲自借券，但系统中需要用现货卖空对冲的那一部分仍受可借库存限制。
- 合约的价值在于增加可以表达的交易理由。衍生品选择少的资产可能增量更大，但越难交易的股票也可能越缺对冲条件，并不天然适合先上。

**用于 Mantle 的推论**：说服团队做 Perps，最直接的方式是展示四类真实需求：方向交易、持仓/做市对冲、现货合约价差、资金费策略。再说明 mStocks 如何作为现货腿和候选抵押资产参与，而不是只强调杠杆、TPS 或交易量。

**对应页面**：P14、P14B、P14C、P14D、P15、P15A、P15B、P20。

## 面向决策者的完整论证

1. mStocks 已确定为核心资产，新增供给之后需要真实使用场景。
2. 只做现货，主要承接买入、持有和卖出的需求。Perps 增加方向表达、对冲、价差和资金费策略，容纳风险偏好不同的参与者。
3. mStocks 能作为其中的现货库存和组合交易的一条腿；如果实现了对应标的与可执行路径，这些参与者才可能把合约需求带回现货。
4. 股票休市和传统工具不足提供潜在差异化，但全天开放不保证始终有可靠价格和充足深度。
5. 因此值得验证的是“同一资产的现货与合约市场能否互相带来有效使用”，而不是“上线 Perps 后交易量必然上涨”。

**本次产品主张**：优先围绕有交易关注、传统工具不足的小市值币股建设链上 Perps，让 mStocks 持有人能对冲、做市商能管理库存、策略资金能交易价差与资金费。链上现货、借贷/借券与策略接口的组合，有机会把这些交易理由转为持续资产使用。

## 需要区分的几组概念

| 容易混在一起的说法 | 本次采用的区分 |
| :-- | :-- |
| tokenized stock 与 stock perp | 前者是具体发行规则下的现货资产表示，后者是价格风险合约；不把 Perps 仓位写成持有股票权益 |
| 做空 Perps 与借现货卖空 | 用户卖出合约不必亲自借券；反向现货对冲依然可能需要库存与借券 |
| 资金费与协议收入 | 资金费通常在多空双方间按规则转移，不能直接算成链或协议净收入 |
| OI、成交量、保证金、TVL | 分别是未了结名义敞口、期间换手、担保资金和资产沉淀，不能互作规模或收入替代 |
| 休市价格与价格领导 | Perps 可以形成候选价格；是否引领重开市场需要同时间口径的证据 |
| 价格参考、成交价、标记价 | 参考价供规则比较，成交价是实际执行结果，标记价用于风险计量；用途不能互换 |
| 可交易与可对冲 | 市场可以接单，不代表正股、现货库存或另一条腿随时可成交 |
