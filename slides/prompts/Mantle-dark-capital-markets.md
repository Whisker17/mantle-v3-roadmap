# Mantle Dark · 产品与资本市场分享制作规范

## 使用方式

这是本次 Mantle v3 **全套 presentation 的当前视觉规范**，适用于 Section 0–4、收尾和附录。先读 [内容索引](../README.md)，再读相应章节。页数和页面顺序以内容稿为准，不再询问已经确定的页数。

内容与视觉各自只有一个依据：章节文件负责上屏文案、图表素材和必要限定，本规范负责颜色、字体与排版。不要把每页的“本页要讲什么”“讲述补充”整段搬上画面。P00 的主题文字必须完整保留。

本规范替代 [旧黄粉手绘提示词](Vibrant-handdrawn-for-young-professional.md)。[旧版 Section 0 PDF](../examples/Mantle%20v3%20%E2%80%94%20Section%200%EF%BC%9A%E4%BB%8E%E8%B5%84%E4%BA%A7%E4%BE%9B%E7%BB%99%E8%B5%B0%E5%90%91%E6%8C%81%E7%BB%AD%E4%BA%A4%E6%98%93-1790416337015.pdf) 只用于理解此前内容，不再作为配色、字形或插画参考。本次改稿不覆盖这份历史 PDF。

## 视觉方向与依据

采用 Mantle 官网的深色方向：**深绿近黑背景、清晰白字、少量亮绿强调，图与证据主导画面**。整体应像产品与技术分享，不做手绘海报，也不把所有文字装进发光卡片。

依据为本次读取的 [Mantle 官网首页](https://www.mantle.xyz/) HTML 中的实际样式：

- 首屏背景 `#040F0B`；导航与深色区另用 `#05100C`、`#06110D`。
- 主按钮 `#00FF93`；首屏图形包含 `#06B680` 和 `#BAFFF5`。
- 深色分区 `#0D100F`，细分隔线 `#1E2924` / `#1E2925`。
- 标识及主要文字为白色；英文资源使用 ABC Monument Grotesk Regular / Medium。

这些是当前网页实现中观察到的视觉取值，不宣称是完整官方品牌手册。以下字号、灰度和版式比例是为投影阅读制定的演示规范。

## 颜色

| 用途 | 色值 | 使用规则 |
| :-- | :-- | :-- |
| 全页背景 | `#040F0B` | 默认覆盖所有页面，禁止改回米白纸张底 |
| 次级区域 | `#0D100F` | 用于表格或图表底；与主背景保持细微层次 |
| 主文字 | `#FFFFFF` | 标题、正文和关键数字 |
| 次要文字 | `#B8C6BE` | 说明与来源，不能低对比到投影看不清；这是演示适配色 |
| 主强调 | `#00FF93` | 每页只突出一个关键节点、结果或短语，不作为大面积正文底 |
| 结构与辅助强调 | `#06B680` | 流程连接、分组与封面局部图形；不用于小号正文 |
| 柔和强调 | `#BAFFF5` | 封面第二层文字或少量辅助信息 |
| 分隔线 | `#1E2925` | 表格分组或真实边界；不承担必须看清的关键连线 |

外部截图保留原有颜色。Fluxion 的蓝/橙、DefiLlama 的蓝/绿都是数据语义，不能为了统一品牌改色或反相。需要额外标记时，用文字和不遮挡数据的标注说明。

## 字体与投影阅读

- 中文使用思源黑体 / Noto Sans SC，可回退 PingFang SC；不用毛笔、涂鸦或手写字。
- 英文如已取得可用字体资源，可用 ABC Monument Grotesk；否则用现有清晰的无衬线字体，不因仿站引入未经确认的字体授权。
- 金额、百分比、bps 使用等宽数字特性，单位保留完整；不靠加粗制造每行都是重点的效果。
- 画幅 16:9，以 1920 × 1080 为基准。左右安全边距约 100 px，上下约 80–100 px。
- 常规标题 56–68 px，正文 32–36 px，图内说明 28–32 px，来源与必要脚注至少 24 px。
- 不照搬网页导航或脚注的 14 px 字号。内容放不下时，减少重复文字或拆分内容，不能整体缩小。
- 每页一个明确结论。图、表、流程按内容需要选择，不强制每页加插画。

## P00 主题页

主题必须为：**从资产供给走向可持续交易，以及产品驱动的 Chain Infra 演进**。

排版采用一个左对齐的标题组，位于画面的中上部，占约四分之三宽度；余下区域留空或仅保留低对比的品牌几何元素。

1. 顶部小眉标：`MANTLE v3`，约 28–32 px。若有官方白色 Logo，可替代部分品牌文字；不用生成图重画 Logo。
2. 主标题分两行，约 88–96 px：`从资产供给` / `走向可持续交易，`。第一行白色，第二行的“可持续交易”用亮绿强调。
3. 主标题下方约 44–48 px：`以及产品驱动的 Chain Infra 演进`，完整保留“以及”，不将后半主题省略为随意口号。
4. 底部仅放三项叙事提示：`资产供给 · 持续交易 · 产品驱动`，约 28–32 px。
5. 可在右下角使用非常克制的绿色情绪光或竖向色带，借用官网首屏图形语言；不画成带坐标的增长曲线，避免暗示真实业务增长。

标题组合的上下留白应大于组内间距。P00 不放议程、数据表、风险条款、人物插画或未提供的演讲者/日期。封面编号是 0；之后先进入 Section 0 分隔页 S0，再开始正文 P01。P00 的精确内容同时见 [Section 0](../sections/01-section-0-review-and-narrative.md)。

## 章节分隔页：S0–S5 与 SA

每个章节文件必须有一张独立 landing page，讲清本章核心主旨。P00 是整场主题页，不替代 S0；S5 对应收尾，SA 对应问答附录，两者不冒充原始 outline 中新增的章节。

统一采用以下版式，具体文字由各章节的分隔页条目提供：

1. **背景**：使用全稿 `#040F0B`，不另换章节色。沿用安全边距约 100 px。
2. **眉标**：左上显示 SECTION 0–4，约 28–32 px，可用 `#00FF93`。收尾显示“讨论与决策”，附录显示“问答附录”。
3. **章节标题**：左对齐，约 72–84 px，最多按语义分成两行。原纲标题较长时在冒号或自然语义处断行，不删掉章节讨论范围。
4. **一句话主旨**：标题下方约 38–44 px，说明这一章希望听众理解什么；不要只重复标题。
5. **本章路径**：下方用 28–32 px 的三个短标签或轻量关系线表达讲述顺序。真实的并列关系不能画成必须依次实施的升级阶段。
6. **内容控制**：保持留白，不放数据表、复杂架构、截图、项目 Logo 墙或人物插画。章节详细结论放正文，分隔页负责建立主旨和导航。

分隔页内容稿 ID 为 S0、S1、S2、S3、S4、S5、SA，不参与 Pxx/Axx 原有编号重排；导出可以显示连续页码。

## 章节总结页：C0–C5 与 CA

每个章节的最后必须有一张独立总结页，不能用进入下一章的分隔页代替。总结回答“本章得出了什么、为什么影响下一步”，分隔页回答“这一章准备讨论什么”。

- **结论先行**：标题直接表达本章得出的判断，不能只写“本章回顾”“我们讲了什么”。
- **支撑判断**：正文以两到三项为主，从本章案例、比较或已明确的产品主张中归纳。需要时加一句决定下一步的条件，不复制目录或全部技术名词。
- **结论有依据**：每页的制作说明要标明所依据的正文页与原文小节。不得在章末首次出现市场数字、收益承诺、技术选型或新产品范围。
- **条件不丢**：产品定位可以明确，PMF、部署状态和架构选择不能冒充已验证。关键条件直接保留在正文；细节进入备注。
- **形式**：延续深色背景，以明确的结论标题和短正文为中心。可以复用本章已经讲过的少量节点，通常不需要再放密集表格或新截图。不要做成只有大字口号、没有支撑判断的空页。
- **字号**：标题约 56–68 px，结论正文约 34–40 px；优先缩短句子，不降低可读性。总结页不重复分隔页的“本章路径”。

放置位置固定为 `Sx → 本章正文 → Cx`。S0 前另有总封面 P00；SA/CA 包围问答附录。内容稿 ID 不改变已有正文编号，导出可采用连续页码。

## 正文与图表

- 普通内容页使用白色标题与短正文，绿色只突出核心词或有效连接。可用细线分组，不保留旧版黄底卡片、粉色涂抹线、纸纹、胶带和手绘人物。
- 表格采用深底、白字、适当行距。表头可用弱绿区域或短标签，不使用整表高亮。单元格内容不能绕成密集段落。
- 流程关系使用明确箭头与动作标签。共用能力、外部系统和候选方向须有文字区分，不靠颜色猜含义。
- 对比页必须标明比较维度与条件；不因为某列用了强调色，就暗示它是已选路线。
- 可保留少量与官网一致的局部渐变，但不得覆盖截图、降低正文对比或成为循环动画。

## 制作前后检查

- 全稿使用这份深色规范，原黄粉手绘提示词仅作历史记录。
- Section 0 当前共 14 页：P00、S0、P01–P04、P04A、P04B、P05–P07、P07A、P07B、C0。每章均有 Sx 入口与 Cx 总结，附录使用 SA/CA；内容稿 ID 与导出页码分别管理，不丢失插入页。
- 逐章核对总结页：主结论有本章依据，未复制分隔页或目录，未新增未经论证的承诺，关键取舍条件仍然可见。
- Section 2 按原纲顺序适配：2.1 四列需求表，2.2.1–2.2.5 的产品需求与优化方向，2.3 两主线及两支线。不得为套模板重新分类、删掉产品差异或把 Optional 改成已决定实现。
- P00 主题完整，P04 真图实际嵌入，P04A 数据与图一致，P04B 讲清从资产孤岛到多场所、多协议使用的过渡。
- 正文、数据、图例和必要脚注可以正常投影阅读；静态 PDF 不依赖悬停或动画显示信息。
- 只输出“上屏文案”及其对应图表，制作说明与讲述补充进入备注。
- 生成后的 PDF/图片需要逐页查看，核对裁切、文字溢出、截图清晰度和颜色；完成内容设计不能直接宣称已完成渲染验收。
