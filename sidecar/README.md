# Bybit CeDeFi Sidecar 战略协同母篇

> **定位**：全链资本市场的外部动力引擎与业务挂斗（The Exchange Sidecar）  
> **核心使命**：**Bybit 是承销商、做市商与经纪商；Mantle 是交易所与最终清算所。**  
> **核心哲学**：链负责规则公开、撮合透明与无歧视清算；中心化交易所提供顶级标的、自有做市库存与全球 8,000 万用户网络。  
> **决策依据**：锁定决策 D4（全深度整合，拆解为四条可独立推进、独立验收的工作流）。

---

## 1. 为什么叫「Sidecar（挂斗动力系统）」？

在软件工程与分布式系统中，Sidecar 模式是指将主应用程序（Mantle 链）与辅助服务（Bybit 交易所）解耦部署，辅助服务为主应用提供网络中继、安全凭证、流量代理和监控能力，主应用则保持其独立性与鲁棒性：
- **互不侵入**：Mantle 链保持 EVM 与去中心化清算所的公开透明属性，不因为对接中心化交易所而牺牲无许可原则；
- **全速赋能**：Bybit 作为 Sidecar，为 Mantle 注入链上最稀缺的三样资源：**用户（8,000 万）、做市库存（深度点差）、合规资产（自营美股）**。
