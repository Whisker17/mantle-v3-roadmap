# 衍生品专属链原生支持（Perps Dedicated Chain-Native Infra）

> **归属产品**：支柱 3 · 衍生品层（股票 Perps & 全天候对冲市场）  
> **核心命题**：拆解全链上衍生品的核心工程瓶颈，建立保障做市商与清算安全的三大行业首创链原生机制，并在单 Sequencer 框架下完成专属性能调优。

---

## 1. 核心工程真相：为什么 v1 坚决不走纯链上 CLOB？

根据本目录收录的 RISE / RiseX 深度逆向实测（详见 `rise-appspecific-teardown.md`）：
- **CLOB 的残酷 Gas 账单**：纯 Solidity 编写的链上订单簿撮合，**单笔成交需燃烧 240 万–420 万 gas**。
- **Mantle 当前参数物理不可行**：
  - 在 RISE 经过暴力扩容的 **1,500 M（1.5 Ggas）** 超大区块中，可容纳 357–615 笔撮合；
  - 但在 Mantle 当前标准的 **60M 区块** 中，**一个区块只能容纳 14–24 笔撮合**。
- **战略结论**：在未重构执行层虚拟机之前，强行在 Mantle 运行纯链上 CLOB 必将塞死整条网络。因此 **v1 坚定采用 Oracle-based 模式（Ostium / GMX 架构）起步**，轻量高效，零撮合滑点，天然适配 RWA 标的。

## 2. 链原生支持的三大机制空白（全行业首创提案）

为了彻底解决极端行情下衍生品协议穿仓、套利和清算失败的顽疾，Mantle 在执行与排序层引入三大专属机制：

```
 ┌────────────────────────────────────────────────────────────────────────┐
 │                      Perps 专属三大链原生机制                          │
 ├────────────────────────────────────────────────────────────────────────┤
 │ 1. 清算专用保留通道 (Dedicated Liquidation Lane)                       │
 │    - 协议在区块空间中强制保留 10%–15% 专属配额                         │
 │    - 普通交易无论出多高 gas 优先费均不可借用，彻底消除剧烈行情下清算   │
 │      交易被 NFT mint 或投机交易挤出的穿仓风险                          │
 ├────────────────────────────────────────────────────────────────────────┤
 │ 2. 协议强制的「模拟-免费拒绝」(Revert Protection)                      │
 │    - Sequencer 在打包前执行轻量化前置检查                              │
 │    - 对因滑点或时差导致无法执行的止损或爆仓交易，直接从排队池剔除且不   │
 │      收取 gas 费用，避免 Keeper 陷入恶性重试烧钱博弈                   │
 ├────────────────────────────────────────────────────────────────────────┤
 │ 3. 预言机与清算原子绑定 (Oracle-Liquidation Atomicity)                 │
 │    - 打破「预言机喂价」与「清算触发」之间的多区块时间差               │
 │    - 在同一个执行状态转换（State Transition）内，预言机价格更新生效的  │
 │      纳秒瞬间直接触发关联账户的爆仓判断，消除任何 MEV 抢跑套利窗口      │
 └────────────────────────────────────────────────────────────────────────┘
```
