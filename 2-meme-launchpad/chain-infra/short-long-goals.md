# 发行链 Infra：Short / Long 分期（讨论定稿）

> **归属**：支柱 1 · 发行层 · `2-meme-launchpad/chain-infra`  
> **日期**：2026-09-09  
> **性质**：交互讨论后的目标切分，不是实现 spec。机制细节仍见 [`launchpad-chain-spec.md`](launchpad-chain-spec.md)、[`issuance-primitives.md`](issuance-primitives.md)。  
> **第一产品**：meme launchpad（Tape）。链身份是「优待资产发行」，但 **第一期只改发射这一类合约，不先做多应用调度平台。**

---

> ⚡ **【核心 TL;DR】**  
> 1. **Short 只认识 Launch Registry。** 给注册过的发射合约：热点配额（防外溢）、失败 Drop、可模拟 RPC；开盘 FBA 与 Session/任意 gas 能做就做。曲线、毕业、分账留在协议。  
> 2. **「瞬时热点吞吐 / 弹性发射 lane」不进第一期。** 2026-09-09 链上复核：曲线争用导致的失败是滑点，不是账户算力满了。没有实例就不要立项。  
> 3. **Long 才升维。** ASS、LFM、VM Hook、rent、以及 **等 Tape 真把同合约有效成交打满再做的突发容量**。ASS 不是第一页标题。

---

## 0. 从 Meme Launchpad 抽出的发行瓶颈

Meme 发射是资产发行的极端形态：开盘秒级突发、状态打在同一个合约、单笔极小、失败率极高、参与者几乎全是机器、资产大多 48 小时死亡。通用 EVM 的平均 TPS、全局 gas、先到先得/PGA、失败仍扣费，全部对不上这张画像。

下面 8 条只写 **链上实际撞到什么墙**。曲线公式、分账比例、毕业阈值是协议的事，不列入。

### 0.1 瞬时热点吞吐：物理墙存在，生产没撞上 —— **不进第一期**

画像没写错：峰值是「一条曲线 3 秒内的有效成交」，不是全链 TPS。并行 EVM 救不了单账户写。Solana 官方也有墙：`MAX_WRITABLE_ACCOUNT_UNITS = 12_000_000`（anza `block_cost_limits.rs`），扩整块救不了单曲线。

**2026-09-09 复核：这堵墙没有被实盘打满。**

- Pons ORGY：失败是 `SlippageExceeded`，不是 gas 不够；单块已有 11 笔成功买，RH gasLimit 近乎无限。  
- pump.fun NEAN 最热 slot `445509856`：49 笔碰同一曲线，申报 CU 只吃掉 12M 的 **35%**；40 笔失败是 `Custom 3/7/13`。  
- $6.2 亿 WOTF PumpSwap：最密 slot 3 笔成功，申报 CU **7.5%/12M**。

争用作为现象发生了（很多笔打同一条曲线）。**「有效成交因容量进不了块」没有实例。** 加 TPS / 弹性 lane 也救不了滑点单。没有实例就不要用这条去说服做 S2。

→ **不进第一期。** 等 Tape 出现「成功买单排队进不了下一块 / 账户 CU 接近配额」再开弹性 lane。

### 0.2 拥堵外溢：爆款发行税会开到全链

EVM 的 EIP-1559 只有一根全局 base fee。一个 meme 把区块填满，**支付、结算、普通 DeFi 一起变贵**。Robinhood Chain 在股票 meme 爆发后 11 天里 base fee 拉到约 82 倍，美股结算和发射抢同一块空间——这不是「链不够快」，是 **费市场没有热点边界**。

分桶和 LFM 不是一回事：分桶限制「这个合约最多吃多少块」；LFM 让「挤的人自己付拥堵价」。第一期只做前者，后者是 geth 级，进 long。

→ 第一期：S1 白名单合约单块 gas 硬顶（量级 20–25%）。

### 0.3 开盘排序不公：PGA、FCFS、衰减税三条路都歪

开盘价谁说了算，本质是 **出块人怎么排这几秒的交易**：

- **PGA**：谁加小费谁先成交 = 把发行变成狙击拍卖。散户买的是被夹过的价。
- **纯 FCFS**（RH 路线）：不能加小费插队，但赢家变成 **离 Sequencer 最近的 bot**。100ms 出块也只是把共址优势变细，不是公平。
- **按秒衰减税**：Pons 那套依赖「一个块里能走完税档」。Mantle **2 秒一块**，税档退化成 0/2s 两级台阶，脚本一次到位，税打不中人。

所以开盘公平不是应用层再写一个 tax，是这段时间 **不要按到达、不要按 gas 排序**，窗内统一清算。曲线怎么算仍在合约；Sequencer 只认「这是 T0 窗」。

→ 第一期：S3 仅对 Launch Registry 做开盘 FBA（太重就第二包，先用 Spend-Gate + 无公开 mempool）。

### 0.4 失败即惩罚：revert 是 bot 的武器，不是用户的失误

发射场里 50%+ 交易 revert 是常态：滑点被打穿、额度没了、防狙击钩子拒绝、同一槽已经被别人买走。通用 EVM 的规则是 **失败也占块、也扣 gas**。结果：

- bot 可以零收益地刷失败单，抬拥堵、探状态；
- 散户点一次失败，gas 照付，体验上就是「链在抢我的钱」。

对单笔 $5–$500 的发行流，失败费本身就能把零售赶出终端。这不是合约能修好的：合约 revert 时 gas 已经烧了。只有 Sequencer **打包前模拟、必失败的直接丢掉**，才把惩罚从用户身上拿掉（必须配速率限制，否则变成免费打 Sequencer）。

→ 第一期：S4 发射相关 tx 失败 Drop。

### 0.5 交易是机器的：人签 EOA 的链，发射台等于没做

pump.fun / four.meme / Pons 的真实流量不在浏览器连钱包，在 **TG Bot、Photon、Axiom、GMGN**。画像里 90%+ 是脚本或半自动终端。这类用户要的是：

- 点一下就买（不能每笔弹签名）；
- 事先知道「这笔会不会进、按什么规则排、失败会不会扣钱」；
- 口袋里只有稳定币 / 股票代币，不必先换成 MNT 再打新。

链如果只提供 2 秒收据、普通 `eth_sendRawTransaction`、失败照扣，终端接进来也会把用户送去别的链。4337 能凑合，但多一跳 bundler、多一层延迟，狙击窗里打不过 EOA bot。第一期不改协议 AA，把发射合约打进现有 Passport/Paymaster 权限表，并让 RPC **能模拟出发射规则**。

→ 第一期：S5 发射 RPC/预确认；S6 复用 AA。

### 0.6 发行与流动性两段：搬家的那一下就是抢跑窗口

经典发射是两截：内盘曲线募资 → 把钱和币 **提出来** → 去 Uniswap/Pancake **另建一个池**。four.meme 两次被打在「毕业那笔 `addLiquidity`」：攻击者先建好价格更差的 pair，或夹在迁移和第一笔 swap 之间。Clanker / Pons V2 的修法是 **根本不要搬**：曲线从第一秒就活在未来那个 v4 池里，毕业只翻状态位。

这是发行产品的结构缺陷（D1），不是 TPS 问题。第一期用 Uniswap v4 Hook 就能关；不必先做链级 AMM。链后期最多保证不变量——「发行头寸就是池头寸、LP 无出口」——仍然不把 xy=k 写进 geth。

→ 第一期：**协议相变**。链侧 L4 以后再说。

### 0.7 发行规则可被绕：工厂里的 hook 不是链的能力

Launchpad 想强制的东西通常是：限仓、抽成、锁 LP、防老鼠仓。写在自己工厂里，只约束「从我这个合约买的人」。用户把币转到外面、走另一个 router、走未打 hook 的池，规则就消失。fee-on-transfer 代币则是另一极端：为了抽成把 ERC-20 变成邪教币，DEX/聚合器直接当它不存在或报错。

Solana Token-2022 的教训是：规则要挂在 **转账这条必经之路** 上，且对外仍是普通代币接口。EVM 没有这层；ERC-777 试过、重入把 Uniswap 打穿。所以「优待发行」的链身份 = 外表 `transfer`/`approve` 不动，VM 里强制跑已注册 hook。这是改执行层，第一期继续用 v4 hook / 合约分账顶着。

→ 后期：L3。不挡上线。

### 0.8 短命资产胀状态：发行链会被自己的尸体填满

>95% 的发射币在 48 小时内失去流动性，但合约存储、元数据、空池槽位会留在状态树上直到永远。通用链可以装没看见；**以发行为主业的链会按天制造垃圾账户**。这不是开盘 3 秒的问题，是活过 12 个月之后全节点和同步成本的问题。

解法是 rent / 冷存储冻结 / 死池可修剪，带最小押金以免乱发。第一期状态量还骂不上，不做。

→ 后期：L5。

**怎么用这 8 条：** 0.2–0.5 有实锤、进 short（S1/S3/S4/S5）。**0.1 没有「容量打死有效成交」的实例，不进第一期。** 0.6–0.8 是发行链身份，不挡上线。

## 1. 切法

```
Short = 让 meme 发射打得动，且打爆时不挤死 Mantle 其余部分
Long  = 再把 Mantle 做成「资产发行」操作系统（多域排序 + 代币原语下沉）
```

一条能力进 **short**，必须同时：

- 直接服务 meme 开盘负载（突发、同合约写冲突、高 revert、90% bot）；
- 对象可以收成 **一个白名单**（launchpad 工厂 / 曲线 / 毕业 hook），不必先发明域代数；
- OP Stack 上主要是 **Sequencer 政策或现有 AA**，不必先改 STF / 代币标准。

其余进 long，或根本不进链（见 §5）。

## 2. Short term —— 为 meme launchpad 改链

对象：一个 **Launch Registry**。不是支付域，不是 DEX 域。

| ID | 链上做什么 | 对上哪条负载/缺陷 | 刻意不做 |
|---|---|---|---|
| **S1 热点配额** | 白名单合约单块最多吃 ~20–25% gas | D5；RH 全局 base fee 暴涨（11 天 82 倍） | 不为每个 dApp 配规则 |
| **S3 开盘 FBA** | 仅 registry 内、标记 T0 的资产；窗内统一清算价 | 2s 出块上衰减税失效；FCFS 开盘 = 共址抢跑；ORGY/NEAN 的过期 minOut | Sequencer 不读 bonding 公式 |
| **S4 失败 Drop** | 发射相关 tx 模拟失败 → 不进块、不扣用户 gas；配地址速率限制 | ORGY `SlippageExceeded`、NEAN `Custom 3/7/13` 仍上链扣费 | 不是全链免费模拟 |
| **S5 发射 RPC / 预确认** | 模拟结果带「会不会进、FCFS 还是 FBA 窗」 | 机器生态；GMGN/TG 不接 = 没做 | 不先做全链多域模拟器 |
| **S6 账户（复用优先）** | Session Key + 任意 token 付 gas，走现有 Passport/Paymaster，权限表只放发射合约 | 90% bot、1-Click | 不先把 4337 沉进协议 |

~~S2 发射突发容量~~ **已移出第一期**（见 0.1 / L0）。没有「有效成交因容量进不了块」的实例，不能拿滑点 revert 充数。

**Short 最小可对外讲的集合 = S1 + S4 + S5。**  
S3 若第一期太重：开盘抗狙击先用应用层 Spend-Gate + 无公开 mempool，FBA 作 short 第二包，**仍只服务 launchpad**。S6 能复用现有 AA 就进第一包，native 化进 long。

协议层同期要做、但 **不算 chain infra**：v4 单池相变、Fee Key、分账、共享 Quote、Spend-Gate、休市熔断。Short 的链只保证三句话：

> 别挤死别人；失败单别扣散户 gas；终端能模拟出发射规则。

对外一句话（不要讲 ASS，不要讲「我们比别人更能打爆款 TPS」）：

> Mantle 给注册过的发射合约做热点隔离和失败 Drop；开盘可用批结算。不把没有实例的「瞬时吞吐」写进第一期。

## 3. Long term —— 资产发行这条链的身份

等发射台有真实负载和终端，再升维。

| ID | 做什么 | 为什么是后期 |
|---|---|---|
| **L0 弹性发射容量（原 S2）** | 开盘窗给 Launch Registry 保留/临时加一段 blockspace | **没有生产实例。** 触发条件：Tape 出现成功买单因块满/账户配额进不了下一块，而不是滑点 revert |
| **L1 ASS** | 支付 FCFS；发射 FBA→FCFS；DEX 默认非 PGA、PGA 仅 opt-in；跨域降级 | 现在只有一类合约需要特殊排序 |
| **L2 LFM 近似** | 热合约独立拥堵价，别人仍付地板 | 第一期只做 S1 配额；真拆 EIP-1559 是 geth 级 |
| **L3 VM 代币扩展** | 对外 100% ERC-20；对内强制 Transfer Hook + 协议费用路由 | 发行链身份证；第一期用 v4 hook 能绕过 |
| **L4 发行即池不变量** | 链保证「头寸即池、无迁移、LP 无出口」；仍不内置曲线公式 | 先让相变在应用层跑成标准 |
| **L5 状态 rent** | 短命币回收 / 冻结冷存储 | 成功 12 个月后的胀库 |
| **L6 Native AA** | Session key / paymaster 从 AA 栈沉进协议 | S6 验证需求后再沉 |
| **L7 清算保留 lane 等** | 与 perps 共用的块空间保留 | 不是 meme 第一产品 |

L1 的预设赋值（讨论已拍，**不在 short 实施**）：

| 域 | 顺序 | 空间 |
|---|---|---|
| 支付 | FCFS | 不被金融域挤占 |
| 发行 · 开盘窗 | FBA | 弹性发射 lane |
| 发行 · 窗后 | FCFS + Drop | 热合约配额 |
| DEX / 金融 | 默认 FCFS 或短批；PGA opt-in | 普通配额 |
| 清算（更后） | 保留 lane | 不可被普通 tx 借用 |

跨域一笔原子 tx：整笔降级到最严（FCFS、不计优先费），禁止 PGA 腿带动发射腿。域靠链上注册表，不靠函数选择器。

## 4. 已拍决策（分期用，不回头拌）

| # | 决策 | 落在哪期 |
|---|---|---|
| D-infra-1 | 第一期只服务 Launch Registry，不做多应用调度平台 | short 边界 |
| D-infra-2 | 开盘用 FBA，不坚持全程 FCFS（FCFS 留给窗后） | S3 / 应用层过渡 |
| D-infra-3 | DEX 不默认 PGA；PGA 仅 opt-in。无公开 mempool 上主动开 PGA = 引进三明治 | long L1 |
| D-infra-4 | 不发非 ERC-20 标准；扩展必须 `transfer`/`approve` 表面兼容 | L3 |
| D-infra-5 | Bonding 数学、毕业阈值、衰减税 **不进 runtime** | 全期红线 |
| D-infra-6 | 合规：Sequencer 入口可做公开制裁筛；不做 Elara 式按 hash 杀交易当产品；股票腿用 Adapter/Hook；meme 默认无许可 | 旁路，见 `outputs/05-compliance-and-permissioning.md` |
| D-infra-7 | **不把「瞬时热点吞吐」写入第一期。** 曲线争用的实锤是滑点/失败扣费，不是容量。弹性 lane 降为 L0，触发条件见上 | 2026-09-09 链上复核 |

## 5. 明确不进链（全期）

- Bonding 公式、毕业阈值、按块衰减税  
- 新代币标准（非 ERC-20 表面）  
- 链级 AMM 引擎（与 Uni / 聚合器对着干）  
- 全局 PGA，或把 PGA 当成 DEX「必需品」  
- 按 txHash 随意作废当 KYC  
- 把 Sequencer 政策做成不可审计的黑盒偏心（即便 short 只有一个 registry，规则也要公开）
- **用滑点 revert 当「瞬时吞吐不够」的证据**（那是 S4/S3，不是 L0）

## 6. 对上最初四条需求

| 原需求 | Short | Long |
|---|---|---|
| 瞬时执行容量 | **不做。** 没有实例。失败用 S4 Drop | L0 仅当 Tape 打满成功成交配额 |
| 热点隔离 / LFM / 弹性空间 | S1 分桶（RH 82× 是外溢实例）。弹性 ≠ 隔离 | L2 LFM；L0 弹性另说 |
| 发行 × 流动性组合 | **协议**：v4 相变、Fee Key、共享 Quote | L4 不变量升链；公式永不进客户端 |
| 机器化交易生态（RPC/bot/MEV/钱包） | S4 Drop + S5 RPC；S6 复用 AA；维持无公开 mempool | L6 native AA；L1 后 RPC 再暴露多域规则 |

---

## 7. 建议落地顺序

1. Launch Registry + **S1 配额 + S4 Drop + S5 RPC**  
2. **S3 FBA**（对付 ORGY/NEAN 那种过期 minOut）和 **S6**（若终端 1-Click 已被卡住）  
3. L3 / L4 / L2（执行层身份）  
4. L1 ASS  
5. **L0 弹性容量**（仅当出现成功单因块满进不去）  
6. L5 rent、L7 清算 lane  

机制怎么做（分桶预测、FBA 窗、Drop 与速率限制、ERC-20 hook 形态）写在 [`launchpad-chain-spec.md`](launchpad-chain-spec.md)。本文只锁 **何时做、为谁做、什么不做。**
