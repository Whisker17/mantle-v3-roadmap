# 第三部分：Launchpad 产品缺陷抽象与优化方向

> **归属工程**：Mantle V3 资本市场体系 · 支柱 1 · 发行层工程输入  
> **文档位置**：`2-meme-launchpad/outputs/04-defects-and-optimizations.md`  
> **目标受众**：CTO、协议架构师、产品负责人  
> **核心使命**：把第二章的三代踩坑史抽象成可复用的缺陷图谱；再把 Robinhood Chain 近两周（约 2026-08-25 ~ 09-08）真正在跑的新产品拆开，看它们各自补了哪一块、哪一块还没补上。结论全部指向 Mantle 自建 Launchpad 的优化清单。

---

> ⚡ **【全篇核心 TL;DR】**：  
> 1. **六大结构性缺陷**贯穿三代产品：**毕业迁移攻击面、创作者老鼠仓、Quote 碎片化、内生注意力枯竭、链级排序/拥堵、真实资产耦合（休市/公司行动）**。每一代都修掉前一代的一两项，同时制造下一代的新死锁。  
> 2. **Robinhood 三代（Pons / LONG / PAIR）并没有把缺陷清零**：Pons 修好了迁移和老鼠仓，但还在用 ETH Quote、还在抽 1% 走 5 年金库；LONG 修好了空气资产，但单股孤立池 + 休市脱锚已经真实爆过（BONER 囤 53% HIMS、周末 4.6x）；PAIR 修好了“单股 vs ETH”的叙事，但聚合器**不做池间再平衡**，peg guard **只暂停新发射、不熔断已有池**。  
> 3. **近两周生态在补的，是“侧车”而不是 Launchpad 内核**：`pools.trade`（Uniswap 自己下场）、`Rialto PropAMM`（薄流动性最优执行）、`Morpho`（Earn / 借贷）、`Lighter`（永续）、`GMGN`（执行层吃 40% 量）、PAIR 的 **peg guard + 周末做市商招募**。它们各自对准一个 RH 缺陷，**没有任何一个产品同时关掉“休市脱锚 + 碎片化 + Gas 外溢”这三扇门**。  
> 4. **Mantle 的优化方向已经收敛**：共享 Quote 水库（破碎片）、v4 单池相变（破迁移）、休市熔断 Hook + Atomic RFQ（破脱锚）、Sequencer 分桶（破 82 倍 Gas）、Fee Key（破老鼠仓）、Spend-Gate 而非 15 秒衰减税（适配 2 秒出块）。

## 3.1 抽象层：Launchpad 产品的六大结构性缺陷

> ⚡ **TL;DR**：不要按“哪条链、哪个品牌”记历史，按**缺陷类型**记。六类缺陷覆盖了从 pump.fun 到 Pons 的全部工程决策。每一类都有“前代怎么修 → 修完还剩什么 → Mantle 该怎么接”。

三代产品表面上换了链、换了 Quote、换了 AMM 版本，底层其实在反复修同一张缺陷表。把它们抽出来，才能避免 Mantle 再走一遍别人已经付过学费的路。

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 结构性缺陷（跨三代不变的问题骨架）                                      │
├──────────────────────────────────────────────────────────────────────────┤
│ D1 毕业/迁移攻击面   │ 两阶段资金搬运 = 夹子窗口 + 重入面                 │
│ D2 创作者激励======= │ 一次性奖励 = 逼出老鼠仓砸盘                       │
│ D3 Quote 与流动性==== │ 多资产孤立池 = 买盘切碎 + 双重滑点 + 死锁资本     │
│ D4 注意力来源======= │ 纯空气内生热度 = 48 小时死亡螺旋                   │
│ D5 链级排序与拥堵=== │ PGA / 全局 Base Fee = 夹子或挤垮主业               │
│ D6 真实资产耦合===== │ 7×24 链 vs 5×8 股市 = 休市脱锚 / 公司行动 / 假标的 │
│ D7 合规权限放错层=== │ 无许可发射 × 受监管 Quote（见 05 补章）            │
└──────────────────────────────────────────────────────────────────────────┘
```

### 3.1.1 D1：毕业与迁移攻击面

> ⚡ **TL;DR**：凡是“内盘曲线 → 提取资金 → 外部 DEX 建池”的两阶段，就会同时打开 MEV 夹子窗口和跨合约重入面。二代 Clanker / 三代 Pons V2 用 **Uniswap v4 单池就地相变**把这条缺陷从物理上关掉了。Mantle 必须直接抄这一步，不要再写迁移合约。

| 代际 | 怎么修 | 修完还剩什么 |
|---|---|---|
| Gen 1 pump.fun | 没有修。`MigrateV2` 是独立交易 | 同块三明治夹击散户冲锋盘；虚拟储备蒸发导致深度断崖 |
| Gen 2 four.meme | 还是外部迁到 Pancake | **Helper3 重入被盗 $183K**（违反 CEI） |
| Gen 2 Clanker | **取消曲线，100% 单边直上 v4** | 开盘无买盘保护，Block 0 被秒狙，后来用 80% 衰减税补丁 |
| Gen 3 Pons V2 | 曲线用**未来池同一种 Quote**募集，毕业时直接铸 full-range v4 头寸；官方原话 *“no router, no swap, and no price oracle”* | 毕业交易仍是一笔独立 `graduate()`，但资金不再跨 Router；夹子窗口从“建池抢第一笔”退化成“毕业瞬间的信息冲击” |

**Mantle 接法**：默认走 Pons V2 / Tape 的 **v4 Hook 状态翻转**，禁止任何 `router.addLiquidity` 外部路径。

### 3.1.2 D2：创作者激励（老鼠仓死锁）

> ⚡ **TL;DR**：不给创作者合法长钱，协议就是在鼓励发币者当骗子。二代用 Fee Key NFT，三代 Pons 用 **5 年线性归属的回购金库（锁仓而非销毁）**。Mantle 应把分成写进不可升级合约，而不是博客政策。

| 代际 | 怎么修 | 修完还剩什么 |
|---|---|---|
| Gen 1 | 打满奖励 0.5 SOL；LP 烧毁，手续费孤儿化 | 全员老鼠仓 |
| Gen 2 Clanker / Flaunch | 无出口 Locker + Fee Key NFT，45%~80% 永续分成 | 社交图谱发币破产后，Fee Key 变成一张没有现金流的空头支票 |
| Gen 2 four.meme | 基础返佣；毕业悄悄抽 2% seeding fee | 信任赤字 + 开盘价剪刀差 |
| Gen 3 Pons | 1% 交易费切成 **30% 协议 / 35% 创建者 / 35% 回购金库**；金库 5 年线性归属，**买回的是该 launch 的 meme，不是销毁** | $PONS 自身 80% 回购销毁是**团队政策，不是合约强制**（分析师已指出可随时改） |
| Gen 3 PAIR | 创建者拿满 70%，协议 30%；无 buyback vault | 创建者激励更激进，但缺少“冷冻流通筹码”的长期机器 |

**Mantle 接法**：Fee Key NFT（可流转）+ 协议收入 **写进合约的 MNT 回购**，不要学 Pons 把最关键的销毁比例留在博客里。

### 3.1.3 D3：Quote 资产与流动性碎片化

> ⚡ **TL;DR**：单一 Quote（SOL/ETH）资本效率最高，但资产叙事最弱；多 Quote（bStocks / 190 只美股）叙事最强，但买盘被切成 155 个浅水洼。**到今天为止，没有任何生产级 Launchpad 做出“统一水库 + 任意 Quote 结算”**。这是 Mantle 最大的空白。

碎片化的四个物理表现（详见第二章补丁，这里只留结论）：

1. **买盘切碎**：全网 $1000 万炒作资金被锁在 155 种股票形态里，新 `GME-Meme` 只能吃到 GME 那一洼；
2. **做市商库存稀释 155 倍**：同一笔资本无法同时给所有池报价；
3. **死锁资本**：95% 归零币把碎股永久冻在僵尸池；
4. **两道浅池滑点相乘**：`USDT → GMEb → Meme`，综合滑点 ≈ $1-(1-s_1)(1-s_2)$。

| 代际 | 怎么修 | 修完还剩什么 |
|---|---|---|
| Gen 1 | 不修，死守 SOL | 汇率漂移（85 SOL 从 $1.7K 漂到 $17K） |
| Gen 2 four.meme | 美元门槛 + 多 Quote | 孤立池碎片化 |
| Gen 3 Pons | 继续 ETH Quote，工程闭环 | 资产叙事弱，吃不到美股注意力 |
| Gen 3 LONG | 单股 Quote（1 meme : 1 stock） | 单股孤立池，双重兑换 |
| Gen 3 PAIR | 1–5 池篮子，USDG 作聚合器公共腿 | **聚合器只优化单笔执行，不做池间再平衡**；休市时外部套利缺席 |

**Mantle 接法**：1inch Aqua 式 **统一 Quote 水库 + JIT 原子结算**。散户 Any-Token In，底层按所选股票/篮子记账。这是三代产品都没做成的那一块。

### 3.1.4 D4：注意力来源（空气 vs 外生日历）

> ⚡ **TL;DR**：机制再精巧，标的是空气就会在 48 小时内死。Base 社交图谱用数据证明了这一点（单币手续费 $1,371 → $53，跌 96%；Jesse Pollak：*I was definitively wrong*）。三代把 Quote 换成美股，等于给 Meme 接上了华尔街的外生注意力引擎。

| 代际 | 怎么修 | 修完还剩什么 |
|---|---|---|
| Gen 1 / 2 | KOL、Farcaster、AI Agent | 内生互割，审美疲劳 |
| Gen 3 LONG / PAIR | NVDA / TSLA / HIMS / SPCX 作 Quote；PAIR 篮子（NVDA+AMD+INTC） | 注意力有了，但**休市 135 小时/周没有股票侧参考价**，外生事件会在周末把池子打穿 |

**Mantle 接法**：继承股票 Quote 叙事，同时必须配 **休市熔断**，否则外生日历会在周末变成外生屠杀。

### 3.1.5 D5：链级排序、夹子与拥堵外溢

> ⚡ **TL;DR**：应用层防夹（私有 RPC、严滑点、衰减税）治标；**Sequencer 规则才治本**。RH 用 100ms + 禁用 PGA 的 FCFS 砍掉了小费插队，但没砍掉全局 Base Fee——11 天涨 82 倍，把美股结算主业勒死。Mantle 2 秒出块还让 Pons 式 15 秒衰减税退化成 7 级阶梯。

| 代际 | 怎么修 | 修完还剩什么 |
|---|---|---|
| Gen 1 Solana | LFM + 单账户 12M CU 硬顶 | Jito tip war，散户买不上 |
| Gen 2 Base | 无公开 P2P mempool | Sequencer **仍按 Priority Fee 重排**；RPC 泄漏；学术论文已证实 rollup 上三明治攻击真实存在 |
| Gen 2 Clanker | 80% 抛物线衰减税 + 2 区块冻结 | 依赖出块粒度 |
| Gen 3 RH | **协议禁用 PGA，FCFS + 100ms**；Pons 99%/15s 衰减税（= 150 个区块） | **全局 EIP-1559 没隔离**；Gas 补贴到 2026-09-29，退出后数据会失真 |

**Mantle 接法**：不要抄 15 秒衰减税（2 秒出块下只有 7–8 档）。用 **Spend-Gate 额度门禁 + Sequencer 热点分桶（单合约 ≤ 20%–25% Gas）+ 非热点保留区**。衰减税最多当辅助。

### 3.1.6 D6：真实资产耦合（休市、公司行动、假标的）

> ⚡ **TL;DR**：一旦 Quote 变成股票，Launchpad 就不再是纯 Crypto 产品，必须处理传统金融的日历、公司行动和发行人垄断。RH 在资产层有工具（唯一 AP 增发、暂停预言机），在 **第三方 AMM 池层完全放任**——这是 HIMS / AMC / Farmmi 三起事故的共同结构。

七类已发生或未关闭的风险（来自 PAIR 对照实测）：

| 风险 | 是否已发生 | 现状 |
|---|---|---|
| 休市陈旧价 | ✅ HIMS 4.6x、AMC 35x | 每周 135+ 小时无股票侧参考价 |
| 周一跳空回补 | ✅ 隐含于上 | 协议层无熔断 |
| 逼空囤积浮筹 | ✅ BONER 囤 53% 全网 HIMS | 单池可吸干一只股票代币的链上流通 |
| 公司行动脱钩 | ⚠️ 未爆 | ERC-8056 改 `uiMultiplier`，**池层没有任何再平衡** |
| 发行人停摆 | ⚠️ AMC 争议期间几乎发生 | 只有 Bitstamp/BBVI 能 mint/redeem |
| 不相关资产 IL | ✅ 结构性 | meme 与股票不相关，永久锁仓 LP 吃满无常损失 |
| 假冒标的 | ✅ Farmmi / JINQIAN | meme 配对了一个匿名铸造的假“代币化 FAMI” |

**Mantle 接法**：资产层抄 ERC-8056（禁止 rebase）；池层必须有 **休市熔断 Hook + 公司行动等价重铸 + 标的白名单/预言机绑定**。这三项 RH 都还没做进 AMM。

## 3.2 Robinhood 上的 Launchpad 还剩什么问题

> ⚡ **TL;DR**：Pons / LONG / PAIR 是分工明确的三件套——Pons 修工程闭环（ETH Quote），LONG 修单股情绪期权，PAIR 修篮子指数。它们**共同没修完的是：休市脱锚、碎片化、Gas 外溢、池层公司行动、假标的**。分产品看，各自还把自己的机制缺陷带进了生产。

### 3.2.1 三件套还在暴露的共同缺陷

1. **休市 135 小时无人值守**：Chainlink Tokenized Equity Feeds 休市冻结最后价，AMM 继续成交。官方工具（停牌、取消订单、Price Deviations 页）**只作用于 Robinhood 自有 App / RFQ / 一级市场，对 Uniswap v4 第三方池零约束**。
2. **散户双重兑换**：钱包里是 USDG/ETH，目标池是 `Meme/NVDA`。没有统一水库。
3. **全局费用市场**：FCFS 防住了插队，防不住 Base Fee 被 Meme 热点抬到 $0.32–0.40/笔。补贴 2026-09-29 截止，之后是真实稳态。
4. **一级市场单点**：唯一 AP（Bitstamp/BBVI）既是纠偏工具（HIMS 事件增发 ~4,000 枚），也是单点故障。
5. **合规切割的政治反噬**：AMC CEO 2026-09-04 公开要求 cease and desist；Robinhood CLO（前 SEC 委员）强硬拒绝。监管对「AMM 交易 linked securities 是否构成 ATS / security-based swap」**零书面表态**——全赛道最大悬空。

### 3.2.2 分产品残留缺陷

| 产品 | 已修好 | 自己还带着的坑 |
|---|---|---|
| **Pons V2** | 零路由毕业；无出口 Locker；99%/15s 衰减税在 100ms 链上细腻 | ETH Quote 吃不到美股日历；$PONS 80% 回购是政策不是代码；`graduate()` 包在 try/catch 里（买单不会回滚，但毕业失败要靠 7 天 rescue delay 兜底） |
| **LONG** | 单股 Quote 被市场用真金白银投票（Artificial Inu/NVDA 市值 ~$275M，NVDA 池深度是 WETH 池 3 倍+） | 单股孤立；逼空浮筹；周末脱锚的直接受害者（BONER/HIMS） |
| **PAIR V5** | 原子发射 1–5 池；永久锁仓；USDG 聚合路由 | 聚合器**不为篮子再平衡**；anti-snipe 只有 5 个区块（0.5 秒）硬上限，比 Pons 弱一个数量级；peg guard **暂停新发射，不暂停已有池交易** |

#### A. 发行层：直接改 Launchpad 形态

**1. PAIR V5 Multipool（2026-08-26 上线，08-31 公开发布 + AWS）**

* **要解决的问题**：LONG 的「1 meme : 1 股票」把流动性锁死在单股浅池；Pons 的 ETH Quote 吃不到美股日历。
* **怎么解决**：一笔原子交易内部署 ERC-20 + **1–5 个 Uniswap v4 池**，创建者从 24 只白名单股票里自选权重（必须加总 100%）。例：33/33/34 → AAPL/MSFT/NVDA，行为上就是三资产指数。每个池用预言机导出的开盘价注入**单边集中流动性**，LP 永久锁进 `PairV4Locker`。没有 bonding curve，没有迁移。“毕业”只是信息性标志位（文化符号沿用 Pons 的 4.2 ETH）。
* **配套补丁 peg guard（09-01 宣布，未完全上线）**：某股票代币链上价相对最后收盘价偏离过大时，**暂停对该标的的新发射**；链上风险标签显示溢价/折价；招募周末做市商。
* **原理要点**：原子性消灭“币已在、池未锁”中间态；篮子分散单股逼空；peg guard 是**发射闸门，不是交易熔断**——HIMS 那种已有池的周末暴涨，它挡不住。
* **规模诚实性**：累计手续费 $433K，是 Pons 的 0.6%。价值在机制完整性，不在体量。

**2. LONG.xyz（单股配对专业户，这两周因 Artificial Inu 被全网讨论）**

* **要解决的问题**：Pons 把工程做绝了，但 Quote 还是 ETH，叙事仍是空气。
* **怎么解决**：创建者选一只 Robinhood Stock Token（NVDA/TSLA/HIMS/SPCX…）作唯一 Quote，从第一笔 swap 就在 `Meme/Stock` 池里交易。
* **市场投票**：Artificial Inu（NVDA）市值 ~$275M；其 NVDA 池流动性 ~$3.3M，**是其 WETH 池的 3 倍以上**。09-02 全链 meme×股票配对成交 >$217M，一度超过底层股票代币自身成交。
* **没解决**：单股孤立、浮筹逼空、休市脱锚——BONER/HIMS 就是它的活体事故。

**3. pools.trade（Uniswap Labs，2026-08-05 上线，这两周与 Pons 互打后和解）**

* **要解决的问题**：Launchpad 抽 1% 太贵；Uniswap 作为毕业目的地，想把发行权收回自己手里。
* **怎么解决**：发币 **0 费用**，交易费 **0.25%**（Pons/PAIR 是 1%）。首日发币数超过 Pons，Pons 当周约 -49%，随后反弹。
* **09-03/04 反转**：Uniswap Labs 买入据报 100 万枚 PONS，“for long-term alignment”。
* **教训（对 Mantle 极重要）**：**Launchpad 护城河不在 AMM、也不在费率**。DEX 用更低费率下场没有压死专业发行层。护城河在发行体验、社区和费用分配设计。

#### B. 交易 / 做市层：给薄股票池补深度和执行

**4. Rialto PropAMM（Rivo Altus 场所）**

* **要解决的问题**：股票代币在普通 AMM 里深度极薄；meme 与股票不相关，被动 LP 吃满无常损失；休市时没有连续报价。
* **怎么解决**：不是 $x\cdot y=k$ 的被动曲线，而是**做市商用链下定价模型连续改价的 PropAMM**，再由 Rialto 作为 best-execution 路由器，把订单在 PropAMM / 普通 DEX 之间择优。链上可组合，区别于 Fluxion 式 RFQ 的“询价但不在池里”。
* **原理**：把 CEX 的库存报价搬到链上，用预言机/内部模型把价差打到几个 bps，专门服务「股票代币这种低自然流动性资产」。
* **没解决**：PropAMM 做市商休市是否持续报价，取决于商业意愿，不是协议强制。它降低滑点，不提供熔断。

**5. GMGN 执行层（不是新协议，但是这两周 RH 上最被低估的“产品”）**

* **要解决的问题**：散户不会在区块浏览器里手动 swap；Launchpad 自己的前端留不住交易。
* **数据**：RH Chain 24h DEX 量里 **GMGN 一家 $641.7M，约 40%**；Pons V2 只有 $161.4M。
* **含义**：价值捕获排序是 **执行层 > 发行层 > AMM**。Mantle 若没有等价终端，做再好的曲线也是给别人做嫁衣。

**6. Ramses CL V2（fee-only 部署）**

* **要解决的问题**：通用 ve(3,3) 排放在新链上制造卖压。
* **怎么解决**：RH 部署改为 **95% 手续费给 LP、5% 给协议/销毁，无 RAM 排放**。代币 RAM 因叙事暴涨，但与 Launchpad 内核无关——它是二次流动性的承接盘。

#### C. 资金与杠杆层：让股票代币不只是 Quote

**7. Morpho（Robinhood Earn 底层）**

* **要解决的问题**：USDG 沉淀在链上吃利息；官方文档写了“用 NVDA 抵押借 USDG”，但缺旗舰实现。
* **怎么解决**：Morpho 作为 Earn 的出借底层（约 7% APY，Lloyd's + RELM 承保），累计手续费 $1.75M。股票代币作抵押目前全链存款仅约 **$72.7M**，仍是空白。
* **对 Launchpad 的意义**：如果毕业后的股票 Quote 不能进借贷，飞轮在“投机层”就断了，变不成资本市场。

**8. Lighter 永续（钱包内原生集成）**

* **要解决的问题**：股票 Meme 只有现货博弈，没有杠杆和休市定价工具。
* **怎么解决**：钱包内嵌永续，承诺 1,100 万 $LIT 给 RH 社区，TVL $64.66M。休市时段 perps 理论上可以承接无法在现货池成交的观点——**但和 AMM 池没有协议级联动**，周末脱锚时 perps 和现货可能各走各的。

**9. 钱包 Gas 代付（产品，不是协议；2026-09-29 截止）**

* **要解决的问题**：Base Fee 已经被 Meme 打到普通用户不可用。
* **怎么解决**：Robinhood Wallet 内 >$0.50 的 swap 全额代付 gas，无上限。
* **这是麻醉剂不是手术**：补贴掩盖了 D5。截止后，82 倍费用模型会暴露真实需求。Mantle 不该学“用国库填全局 Base Fee”，该学“分桶隔离”。

## 3.4 原理解析：这些新产品各自补了哪一块、为什么补不全

> ⚡ **TL;DR**：把近两周产品映射回六大缺陷——**D1 毕业攻击面已被 Pons V2 关掉；D2 激励被 Fee 切分/金库部分关掉；D4 注意力被 LONG/PAIR 接上美股；D3/D5/D6 仍然洞开**。PAIR 的聚合器、peg guard、Rialto 的 PropAMM 都是局部补丁，机制边界写得很清楚，抄的时候不要把“宣布了”当成“链上强制了”。

### 3.4.1 PAIR 原子篮子发射：怎么把 ETF 做成一笔交易

```
createToken() 同一笔原子交易
 ├── 部署固定供应 1B ERC-20（无 mint）
 ├── 创建 1–5 个 Uniswap v4 池（白名单股票作 quote，权重 Σ=100%）
 ├── 按预言机开盘价注入单边 CL 头寸
 ├── 每个 LP NFT → PairV4Locker（无提取路径）
 └── 可选付费 dev-buy
失败任意一步 → 整笔回滚，不存在中间态
```

* **相对 LONG 的进步**：单股逼空变成篮子分散（Chips Party Pack = NVDA+AMD+INTC+MU）。
* **相对 Pons 的退步**：没有 bonding curve 进度条（失去谢林点），anti-snipe 只有 **5 个 100ms 区块 = 0.5 秒** 的 5.5%/5.0% 硬上限，人类用户基本赶不上。
* **关键缺陷（源码级）**：`PairV5MultiPoolAggregator` 用 USDG 作公共腿，拒绝单腿 >15% 冲击，**不为篮子再平衡**。各池价格对齐完全依赖外部套利。休市时套利者缺席 → 篮子在周末会裂成 5 条独立的脱锚曲线。

### 3.4.2 peg guard：发射闸门 ≠ 交易熔断

PAIR 09-01 新闻稿的三件套：

| 组件 | 实际效力 | 挡得住 HIMS 事故吗 |
|---|---|---|
| 偏离过大时暂停**新发射** | 只挡增量垃圾币 | **挡不住**。BONER 已经在池里 |
| 交易前显示溢价/折价标签 | 信息披露 | 挡不住。散户会点确认 |
| 招募周末做市商 | 商业意愿 | 不确定。不是协议强制 |

**Mantle 若只抄 peg guard，等于抄了一个运营开关。真正要抄的是池层 Hook：`if |onchain - lastClose| > X% AND marketClosed → revert large swaps`。**

### 3.4.3 Pons V2 毕业：为什么“同 Quote 曲线”能消灭迁移 MEV

Pons 的关键不在 Uniswap v4 本身，而在这一句设计约束：

> 曲线交易用的 Quote，必须等于未来 v4 池的 Quote。

因此毕业时：

1. `curve.graduate()` 停曲线、清手续费、把 **100% 储备**交给 factory（强制转入的捐赠被排除，防直接打款扭曲毕业价）；
2. 跨越阈值的那笔买单**内部自动触发**，包在 try/catch——毕业失败不会让用户买单回滚；
3. `factory.createGraduatedPool()` 直接铸 full-range v4 头寸进无出口 Locker，可重试，7 天 rescue delay。

没有 Router、没有二次 swap、没有预言机。夹子在 Mempool 里看不到“建池交易”。这是 D1 的标准答案。

**5 年回购金库的原理**：35% 手续费在冲击上限 3% 内把收到的 meme 换回 Quote，再买回**该 launch 的 meme**，锁进 `PonsV2BuybackVault`，加权平均时钟 5 年线性归属。效果是持续抽走流通盘，而不是制造一次性销毁脉冲。注意：这与 $PONS 代币本身的 80% 回购销毁政策是两套系统。

### 3.4.4 LONG 单股飞轮：为什么 NVDA 池可以比 WETH 池深 3 倍

经济循环：

```
散户想表达“看多英伟达财报”
        │
        ▼
买入 Artificial Inu，必须支付 NVDAx
        │
        ▼
NVDAx 被锁进永久 LP（或曲线储备）
        │
        ▼
股票代币链上浮筹下降、成交上升
        │
        ▼
更多人把注意力和库存放到 NVDAx 而不是 WETH
```

这是 D4（注意力）和部分 D2（主业反哺）的正确答案。它同时把 D3 和 D6 放到最大：所有风险都集中在**一只股票的链上浮筹**上。BONER 证明单池可以吸干一只股票代币 53% 的流通量。

### 3.4.5 Rialto PropAMM：薄资产的定价权从曲线交给做市商

```
普通 AMM:  P = f(储备)，被动，休市继续按错误曲线成交
PropAMM:   P = 做市商链下模型(oracle, inventory, risk) → 链上改价
Router:    在 PropAMM 与 Uniswap 池之间选最好的一跳
```

它补的是 **D3 的深度**和 **D6 的部分休市报价**（如果做市商愿意周末挂单）。它不补熔断、不补碎片化、不补 Gas 隔离。Mantle 已有的 Fluxion Atomic RFQ 与它对位——开市锚实时价、休市切 AMM——比 Rialto 更完整，但必须把熔断接到 Launchpad Hook 上，否则第三方池照样脱锚。

### 3.4.6 一张映射表：谁补了哪一刀

| 缺陷 | 已被谁补到什么程度 | 近两周新品有没有补上 | Mantle 还要不要做 |
|---|---|---|---|
| D1 迁移攻击面 | Pons V2 / Clanker：**已关闭** | pools.trade 走同一套 v4 | 直接继承 v4 相变，不要再发明迁移 |
| D2 老鼠仓 | Pons 金库 / PAIR 70% 创建者 / Clanker Fee Key：**部分关闭** | 无本质新品 | Fee Key + 合约级 MNT 回购 |
| D3 碎片化 | **无人关闭** | PAIR 篮子只是把 1 个浅池变成 5 个浅池 | **共享水库 = P0** |
| D4 空气注意力 | LONG/PAIR：**已接上美股** | 同左 | 继承，不要回通用 meme |
| D5 排序/拥堵 | FCFS 关闭插队；**全局 Base Fee 洞开** | Gas 代付是麻醉 | Sequencer 分桶 = P0 |
| D6 休市/公司行动/假标的 | **AMM 层未关闭** | peg guard 只挡新发射；Rialto 靠做市商意愿 | 熔断 Hook + ERC-8056 池层重铸 + 标的白名单 = P0 |

## 3.5 给 Mantle 自建 Launchpad 的优化方向（从缺陷反推）

> ⚡ **TL;DR**：不要做“RH 的更好仿盘”。RH 已经用真金白银证明了美股 Quote 能跑；也用三起事故证明了 **池层熔断、共享流动性、Gas 隔离** 这三件事他们做不到或没做。Mantle 的差异化必须钉在这三件事上，再叠自己独有的 Fluxion RFQ、xStocks 规模和 Bybit 上市阶梯。

### P0（不做就不要上线）

| # | 优化项 | 对应缺陷 | 不要抄的反面教材 |
|---|---|---|---|
| P0-1 | **Uniswap v4 单池相变**，禁止外部 Router 迁移 | D1 | four.meme $183K、pump.fun 夹子屠宰场 |
| P0-2 | **共享 Quote 水库 + JIT**（USDT in，股票 Quote 记账） | D3 | four.meme / LONG 孤立池、PAIR 聚合器不再平衡 |
| P0-3 | **休市熔断 Hook**：市场日历 + 偏离阈值限制大额成交；开市接 Fluxion RFQ | D6 | HIMS 4.6x、AMC 35x；peg guard 只挡新发射 |
| P0-4 | **Sequencer 热点分桶**，单合约 Gas 硬顶，非热点保留区独立计价 | D5 | RH 11 天 82 倍；不要用国库代付全局 Gas |
| P0-5 | **ERC-8056 乘数 + 池层等价重铸**，禁止 rebase | D6 | 第一次分红就会抽干永久锁仓 LP |
| P0-6 | **标的白名单**：只能配对经过发行方/预言机绑定的真股票代币 | D6 | Farmmi 假标的反向传导纳斯达克 |

## 3.6 一句话收束

> 过去的 Launchpad 迭代，是一部「每次修好一个缺陷、再踩进下一个缺陷」的工程史。Robinhood 这一代第一次把 **D4 注意力**接到了真实世界，也第一次把 **D6 真实资产耦合**变成了必须回答的题。近两周冒出的 PAIR 篮子、peg guard、Rialto PropAMM、Morpho、Lighter、GMGN，证明市场已经在用侧车协议补洞——**但洞还在**。Mantle 自建的正确姿势不是再发一个 Pons，而是把 RH 没做成的三件事（共享流动性、休市熔断、Gas 隔离）做成链级能力，再把 Bybit 上市阶梯接在毕业之后。
