# 支柱 4：融资层 —— Margin Lending（融资融券与杠杆资金池）

> **产品定位**：真实资产抵押的融资融券与信贷中枢（Securities Lending & Margin Facility）  
> **核心使命**：拒绝再做一个依赖流动性补贴的通用 Aave Fork，以 **xStocks（代币化股票）与 mETH / cmETH** 作为核心抵押品，打通「现货抵押 ──► 借出稳定币 ──► 加杠杆打新/交易」的真实业务闭环，全面激活 Mantle 链上沉睡的 **$576M 闲置稳定币**。  
> **关联规划**：参考第七部分 7.6 节融资层设计。

---

## 1. 为什么坚决不做通用 Aave Fork？

### 1.1 Aave 在 Mantle 的历史崩塌教训
- Aave 曾作为旗舰借贷协议引入 Mantle，在官方流动性挖矿补贴下，TVL 曾冲高至 $704M。
- 但补贴退坡后，雇佣兵资本（Mercenary Capital）在 4 天内撤离 72%，TVL 暴跌至 $62M，甚至低于补贴前的基线。
- **根本原因**：普通的「存 ETH 借 USDC 吃息」在各 L2 间同质化极其严重，没有原生业务需求的借贷池只是资金盘套利工具。

### 1.2 Mantle 独有的商业闭环：融资融券（Margin Trading）
在成熟资本市场中，证券借贷是交易活跃度的倍增器。Mantle 的借贷协议应专注于服务交易场景：
- **经典需求路径**：
  $$\text{持有 NVDAx / TSLAx} \longrightarrow \text{质押借出 USDT} \longrightarrow \text{参与 Tape 曲线打新或股票 Perps 套利}$$
- **资金供给端**：Mantle 链上拥有 **$576M 闲置稳定币**（为链上 DeFi TVL 的 5.9 倍），资金出借端供给极其充沛，亟需低风险的真实借贷需求来获得稳健收益。

## 3. 风控体系：与市场日历与熔断 Hook 联动

由于 xStocks 的底层证券存在夜间与周末休市，借贷协议必须具备专业的证券风控机制（与 `chain-infra` 共享同一套日历基础设施）：
1. **休市动态折价（Weekend Haircut）**：
   在美股周五收盘前，系统动态降低 xStocks 的最大可借贷比率（LTV）或提高清算阈值，防范周一开盘跳空导致的穿仓。
2. **预言机陈旧度检查（Staleness Protection）**：
   休市期间 Chainlink 股票预言机无心跳更新。借贷合约自动锁死价格快照，禁止基于休市前价格恶意套现借出流动性。
3. **与清算专用 Lane 协同**：
   在发生全网极端波动时，借贷协议的清算调用自动路由至 Mantle Sequencer 的专属清算通道，防止因链上拥堵导致呆账坏账。

## 4. 北极星 KPI

- **稳定币链上利用率（Stablecoin Utilization Rate）**：衡量 $576M 闲置资金被激活的真实比例。
- **xStocks 抵押总量（xStocks Collateral Volume）**：进入借贷池的代币化股票绝对规模。
- **不良贷款率与穿仓损失（Bad Debt Ratio）**：经历美股极端财报季后的零穿仓表现。
