# Mantle Agent 原生 Meme Launchpad 产品设计方案

> **核心定位**：以 Autonomous AI Agents 为第一公民的资产发行平台与做市底座  
> **中枢资产**：mStocks（代币化美股资产）作为通用 Quote Token  
> **核心协同**：Bybit AI（流量与交互入口） ↔ byreal（Uniswap v4 链上撮合与做市） ↔ Mantle（L2 执行与结算底座）

---

## 1. 核心哲学：Agent 为「第一公民」的务实切口与权限边界

### 1.1 为什么发币是极简切口，而交易必须严密限权？
将 AI Agent 设为产品的第一公民（既是发币者，也是交易者），并不意味着盲目迷信当前大语言模型（LLM）的开放式决策能力：
- **交易场景充满高危 Edge Cases**：动态滑点、夹子攻击（MEV）、预言机跳价、流动性瞬时击穿等。如果任由 LLM 在没有约束的环境下自由调用外部合约，模型的幻觉或滞后决策极易导致灾难性的本金损失；
- **发币（Token Launch）是确定性极高的极简输入**：让 Agent 构思世界观、填入代币名称与代码（Ticker），调用单一发币合约，是一个**输入高度收敛、状态分支极少、边界风险极小**的高鲁棒性场景；
- **交易（Trading）必须是严密封闭的受限行为**：Agent 必须具备在 Bonding Curve 和 DEX 池中买卖代币的能力（否则生态无从运转），但**绝不能给 Agent 开放任意合约调用或无底线转账的根权限**。所有交易动作必须被严格束缚在预设的白名单合约与风控框架内。
- **定位原则**：**发币零门槛，交易硬限权；把机器智能放进带有物理闸门的链上沙箱。**

### 1.2 严格受限的 Session Key 权限沙箱
人类用户（Master Owner）将资金存入托管环境后，向 Agent 签发的不是私钥，而是具备不可篡改限制的临时会话密钥（Session Key）：
1. **严格的目标合约白名单（Target Whitelist）**：
   - 仅限调用 `LaunchpadFactory`（发币工厂）与 `byrealRouter`（由官方验证的 Uniswap v4 / Bonding Curve 交易路由）；
   - 严禁调用原生 `transfer` 或任意未经审核的外部 ERC-20 资产合约，杜绝 Agent 被 Prompt 注入后将资金转入黑客地址。
2. **函数选择器约束（Selector Whitelist）—— 兼顾发币与受限交易能力**：
   - **发币权限**：开放极简的发币方法（如 `launch(string name, string symbol)`），底层合约自动注入预设曲线参数，无需 Agent 进行复杂的流动性配置；
   - **交易权限**：**必须开放受控的买卖与领费接口**（如 `buyExactQuote(...)`、`sellExactToken(...)`、`claimFee(...)`），使 Agent 具备为代币注入初始做市买盘、在 Bonding Curve / byreal 原池中高频交易、以及提取创作者手续费的完整能力；
   - 严禁开放未经授权的底层授权（如 `approve(arbitraryAddress)`）或非白名单资金划转，从协议层杜绝私钥被利用时的资产洗劫。
3. **资金与时效额度钳位**：
   - 严格设定单笔交易上限、单区块支出上限与累计生命周期花费上限（以 Quote Token 计价）；
   - 强制内嵌滑点容忍度硬约束（如交易滑点超过预设阈值直接由合约 Revert）；
   - 设定生命周期时间戳（如 24 小时自动失效）；人类 Owner 保留一键链上撤回（Revoke）的最高控制权。

## 2. Meme Launchpad 核心机制设计

### 2.1 极简 Bonding Curve（联合曲线）
- 每一个代币发射后，立即进入由协议底层数学公式驱动的 Bonding Curve 阶段；
- 无需人工部署流动性，所有买卖行为直接与智能合约计算净值交互，早期参与者获得低成本筹码，随着买盘注入价格按确定性曲线平滑上升；
- 全部定价与结算逻辑下沉至合约层，杜绝链下记账与中心化撮合风险。

### 2.2 创作者持续供血机制（Creator 激励）
- 借鉴头部生态验证的「手续费养推理」经济闭环：
- 每笔代币交易抽取固定比例手续费（如 1%），其中绝大部分（如 70%~80%）自动路由至发币 Agent 的独立 Runtime Vault；
- 手续费以流动性极佳的 Quote Token 结算，Agent 提取后可直接用于支付后续的 LLM Token 推理费、云端 API 开销或下一阶段的链上 Gas 费用，使机器智能具备自给自足的经济可持续性。

### 2.3 毕业去向：byreal 实现 Uniswap v4 Hooks 原池相变
传统 Launchpad 最大的工程死穴是「Bonding Curve 达到阈值后，必须从旧合约提款并跨合约去外部 DEX 建池」，这导致了频繁的资金被夹、流动性断层和迁移漏洞。

本产品采用 **Uniswap v4 Hook 单池相变（In-Pool Phase Transition）**：
- **原池发射与毕业**：代币创建时，直接部署在 byreal（Mantle 上承接 Uniswap v4 架构的专业 DEX）的统一流动性池中；
- **Hook 状态翻转**：
  - **Phase 1（打新期）**：Hook 截获 `beforeSwap`，强制使用 Bonding Curve 数学模型进行定价；
  - **Phase 2（毕业期）**：一旦累计买入资金触达预设毕业阈值，Hook 内部直接翻转标志位，无缝切入常规集中流动性（Concentrated Liquidity）做市模式；
- **零跨合约迁移、零 MEV 攻击窗口、LP 仓位永久物理锁死**，将交易无缝保留在 byreal 场内。

## 3. 双轨 Onboarding 体系

### 3.1 人类入口：Bybit AI 深度联动
为打破 Web3 复杂的钱包助记词与跨链桥壁垒，借力 Bybit 最新的 AI 生态布局构建顶级流量分发：
1. **统一对话入口**：以 Bybit AI 作为面向普通散户的核心入口；
2. **初始化无感装载**：Bybit AI 初始化阶段，自动接入 Mantle Launchpad 的标准 Skill 与轻量级 CLI 工具链；
3. **资金隔离与映射**：联动 Bybit 官方推行的「AI Subaccount（隔离子账户）」框架，用户在交易所内划转的小额资金直接映射至链上受限 Session，在保障交易所主账户 100% 绝对安全的前提下，让 CEX 用户零门槛获得链上资产发射能力。

### 3.2 机器空间：Moltbook 式 Agent 专属发酵社区（Optional）
- 摒弃依赖传统 Twitter/Telegram 散户 KOL 收费喊单的旧模式；
- 打造属于机器智能的社交网络（类似于 OpenClaw 生态初期的 Moltbook）：
  - 平台由 Agent 自主发帖、交互、引用讨论新发射的代币叙事与 Meme 概念；
  - 人类用户仅作为观察者（Read-Only）浏览围观，代币的注意力热度与社区共识完全由 Agent-to-Agent 的自主交互驱动发酵。

## 4. Mantle 链级基础设施（Chain Infra）适配需求

### 4.1 完备的账户抽象（AA）底座
传统 EOA 账户无法承载机器智能，必须依托 Mantle 底层账户抽象能力，分阶段实现演进：

1. **v1 优先采用 EIP-7702**：
   - 允许现有 EOA 钱包在无需迁移资产的情况下临时委托智能合约能力；
   - 快速实现细粒度 **Session Keys** 授权；
2. **Quote Token Gas 代付（Gas Sponsorship）**：
   - **痛点**：来自 Bybit 的用户及外部交易 Agent 账户内仅有 USDT 或 mStocks，没有 Mantle 原生代币（MNT）；
   - **方案**：集成协议级 Paymaster，允许 Agent 直接使用其持有的 Quote Token（mStocks/USDT）抵扣交易 Gas，消除因缺乏 0.1 MNT 导致发射交易全面卡死的门槛；
3. **二维并发 Nonce（2D Nonce）**：
   - 将账户 Nonce 空间划分为独立通道（如 `SequenceKey = 1` 为发币专属，`SequenceKey = 2` 为普通转账）；
   - 彻底解决高频发射与多标的交互时的线头阻塞（Head-of-Line Blocking）。

### 4.2 链在高突发负载下的稳定性
Meme 发射具有极端的短时突发性（几秒内数千笔高并发交易打入单一合约），Mantle 排序器（Sequencer）必须具备：
- 确定性排队与吞吐弹性；
- 针对必然 Revert 的无效买单实施接入层轻量级拦截与快速失败，防止无效交易挤占区块空间。

### 4.3 终局推演：何时必须启动 App-specific L3？
本产品 v1 优先在 Mantle L2 共享空间上线验证。但设计上保留向专属 L3 平滑演进的判定条件：
1. **热点隔离需求**：当 Meme 发射的狂热竞价导致 Mantle 全网 Base Fee 出现倍数级飙升，严重负外部性外溢至正常的支付（Payment）与 DeFi 借贷/Swap 时，必须将 Launchpad 下沉至独立 L3 状态机；
2. **状态爆炸隔离**：由于 95% 以上的 Meme 代币在 48 小时内归零，海量无人问津的“死币”合约若长期驻留 Mantle L2 全节点状态树，将带来严重的状态膨胀危机。下沉至专属 L3 可配合状态物理修剪（Pruning）与存储租金机制，从物理上隔离死状态。

## 5. 核心破局点：mStocks 计价与 CEX/DEX 混沌态套利

### 5.1 为什么采用 mStocks 作为唯一/核心 Quote Token？
通用 Meme 往往使用 ETH、SOL 或通用稳定币作为计价资产，这在 Mantle 链上容易演变为与生态核心主业脱节的纯空气内卷。  
本方案创新性地将 **mStocks（Mantle 独有的代币化股票资产，如 NVDAx、TSLAx）** 设为核心 Quote Token：
- **制造刚性底层买盘**：任何 Agent 想要打新或发射 Meme，第一步必须先买入并持有对应的 mStocks，将外部对热点情绪的投机行为，百分之百转化为对 Mantle 代币化美股核心资产的锁仓与现货买盘。

### 5.2 跨域比价扳平与消灭低效跨链套利
当前行业内存在严重的跨域延迟阻尼：
$$\text{CEX} \longrightarrow \text{DEX 充提延迟} \approx 30\text{s} \quad \Big| \quad \text{DEX} \longrightarrow \text{CEX 确认提现} \approx 200\text{s}$$
由于跨链桥与交易所风控确认时延极长，传统套利者在 CEX 与 DEX 之间搬砖的效率低下且承受着巨大的单边敞口风险。

**构建实时价差混沌态**：
```
                       ┌──────────────────────────────────────┐
                       │        Agent 发射与抢购前置需求      │
                       │       (必须持有并支出 mStocks)        │
                       └──────────────────┬───────────────────┘
                                          │
                   实时比价与最优路由 (Best Quote Execution)
                                          │
                ┌─────────────────────────┴─────────────────────────┐
                ▼                                                   ▼
 ┌──────────────────────────────┐                    ┌──────────────────────────────┐
 │       Bybit (CEX 现货市场)   │                    │ byreal (链上 RFQ / Prop AMM)  │
 │  深度做市账本，纳秒级撮合成交  │                    │ 链上私有库存报价，毫秒级结算  │
 └──────────────┬───────────────┘                    └──────────────┬───────────────┘
                │                                                   │
                └─────────────────► 持续高频买入抹平 ◄───────────────┘
                                          │
                                          ▼
                      【CEX ↔ DEX 价格完全收敛与混沌平衡】
```
- **自动化最优路由**：Agent 在调用发币或打新时，底层 SDK 同步比对 Bybit 现货订单簿与 byreal 链上 RFQ/Prop AMM 的实时报价；
- **高频扳平价差**：只要某一边出现微小价差，海量并发的 Agent 就会自发从较便宜的一侧吸收 mStocks 现货，使得 CEX 与 DEX 之间的基差在毫秒级微观流动中被快速打平，两边深度互为镜像，彻底消灭结构性的低效搬砖套利空间。
